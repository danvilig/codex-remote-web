# Codex Remote Web 0.2.0-alpha.3

Native executable packages now include **macOS Apple Silicon** and **Windows x64**, alongside Linux x64/arm64. Bundled runtimes and terminal modules require no Bun/Node installation or compilation.

- Use `macos-arm64.dmg` (drag the app into Applications) or `windows-x64.msi` (per-user installation, Start menu and uninstall support). Portable `macos-arm64.tar.gz`, `windows-x64.zip` and `linux-{x64,arm64}.tar.gz` are also available. Keep the extracted folder intact; Codex CLI and Git must be installed/configured separately.
- Verify the adjacent `.sha256` (`shasum -a 256` on macOS, `Get-FileHash -Algorithm SHA256` on Windows). Linux also offers `deployment-linux-*` archives for installations using their own runtimes.
- Set `CODEX_WEBUI_CWD` to your project and run `./codex-remote-web` (PowerShell: `.\codex-remote-web.exe`). Open **http://127.0.0.1:8899**.

Requirements: glibc Linux, macOS 15+ arm64, or Windows 11 x64 with NTFS and Windows PowerShell. macOS Intel, Windows ARM64 and musl are unsupported. macOS/Windows packages are unsigned; use per-file system approval only for trusted downloads, never disable OS protections globally.

The automatic fixed-domain service wizard requires Linux systemd. macOS/Windows use manual Cloudflare Tunnel + Access setup; protected temporary access supports Linux/macOS only. Never publish an unauthenticated local gateway. See [platform setup](../deployment/PLATFORMS.md).

Upgrade into a separate directory, stop gateways sharing the same state before switching, and retain configuration, projects, credentials, receipt/queue files and SQLite locks. Roll back by restoring the previous installation; do not clear execution records or move existing release tags. Alpha limitations remain: uncertain execution is never automatically replayed, native exactly-once and strict Desktop race prevention are not promised, and Side chat is temporary.

新增 **macOS Apple Silicon** 与 **Windows x64** 可执行包，继续支持 Linux x64/arm64。包内置运行时和终端模块，无需安装 Bun/Node 或编译；需自行配置 Codex CLI、Git。

推荐 macOS DMG（拖入 Applications）或 Windows MSI（当前用户安装、开始菜单、可卸载），也可选择便携包；安装器不添加后台服务。下载对应包与 `.sha256`，核对校验和，保留完整解压目录。设置 `CODEX_WEBUI_CWD` 后运行 `./codex-remote-web`（PowerShell：`.\codex-remote-web.exe`），打开 **http://127.0.0.1:8899**。

要求 macOS 15+ arm64、Windows 11 x64（NTFS、Windows PowerShell）或 glibc Linux；不支持 Intel Mac、Windows ARM64、musl。macOS/Windows 包未签名，请仅批准可信文件，不要全局关闭系统保护。自动部署向导仅支持 Linux systemd；其他平台请按[跨平台配置](../deployment/PLATFORMS.md)手动配置 Tunnel + Access。Windows 暂不支持临时访问。

升级请使用独立目录，切换前停止共享状态的网关，保留配置、凭据、项目、回执、队列及 SQLite 锁；回退恢复旧安装，不清空执行记录。Alpha.2 的协议及恢复限制仍适用。


Windows 文件内容在原子替换前执行 flush，但 Node/Bun 不提供目录 fsync，因此不承诺突然断电时目录项的落盘保证；保留回执、队列及 SQLite 状态，恢复时核对未知结果，不自动重放。多用户共享存储和跨主机队列不属于支持范围。

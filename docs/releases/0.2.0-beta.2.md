# Codex Remote Web 0.2.0-beta.2

This candidate replaces the macOS, Linux and Windows gateway runtime with a stripped Go executable and includes the browser assets and native terminal. The macOS application uses system AppKit and WKWebView, while Windows and Linux desktop settings use Electron. Linux also uses the same Go gateway in its deployment archives and Docker image. The gateway itself does not require Bun or Node.js.

Codex CLI and Git remain separate requirements; remote access requires cloudflared. The macOS installation floor remains Apple Silicon with macOS 15. Test DMGs are ad hoc signed; the CI signature check does not establish publisher trust. The [candidate checks](0.2.0-beta.2-acceptance.md) track both mounting and launching the exact DMG on macOS 15 and 27.

Before upgrading, stop previous gateway processes sharing the same state and back up the configuration, pending submissions, queues, and lock databases. Keep the previous distribution and service configuration for rollback, and avoid concurrent writers during the transition. The macOS app can remove its own background components and local app data from Diagnostics while preserving Codex credentials and projects.

# Codex Remote Web 0.2.0-beta.2

This beta ships a lighter desktop app for macOS, Windows, and Linux. The native Go gateway runs without Bun or Node.js, and the desktop app uses the system WebView instead of bundling Electron. In pre-release checks, desktop installers were about **7–8 MB**, and the installed application files totaled about **16–26 MB**, excluding shared system dependencies and user data.

- **Resume existing work.** Open a project folder to load its existing Codex conversations. Remove a project from the sidebar without deleting its files or conversation history.
- **Better macOS integration.** A clearer Finder installer, native menus, and an in-app language switch. Diagnostics can remove the app and its background components while preserving your projects and Codex history.

**Compatibility:** Apple Silicon with macOS 15 or later, Windows 11 x64, and Ubuntu 24.04 x64 or ARM64. See the [installation and upgrade guide](https://github.com/danvilig/codex-remote-web/blob/3a02972d281c518389ec2fb634197a881a791e81/docs/deployment/PLATFORMS.md).

## 中文

本次 Beta 为 macOS、Windows 和 Linux 提供更轻量的桌面应用。网关改用原生 Go，无需 Bun 或 Node.js；桌面界面使用系统 WebView，不再打包 Electron。发布前测试中，桌面安装包约 **7–8 MB**，安装后的应用文件约 **16–26 MB**，不含系统共享依赖和用户数据。

- **接续原有工作。** 打开项目目录即可加载已有的 Codex 会话；从侧栏移除项目时，文件和会话历史会保留。
- **更贴合 macOS。** Finder 安装指引更清晰，支持原生菜单和应用内语言切换。可在诊断页清理并卸载应用及后台组件，项目和 Codex 历史会保留。

**兼容性：** 支持 Apple Silicon（macOS 15 及以上）、Windows 11 x64 和 Ubuntu 24.04 x64／ARM64。详见[安装与升级指南](https://github.com/danvilig/codex-remote-web/blob/3a02972d281c518389ec2fb634197a881a791e81/docs/deployment/PLATFORMS.md)。

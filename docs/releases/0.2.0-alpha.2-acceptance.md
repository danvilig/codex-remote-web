## 恢复与权限边界

- 应用层提交记录和会话锁不等于原生 exactly-once。当前原生协议没有条件式空闲启动；Desktop 可以在网关检查空闲后启动任务，这一跨应用竞争不能由本应用的锁彻底消除。
- 无法确认是否接受的提交不得自动重发；仅使用明确的消息关联标识核对，不能用相似文本推断成功。重启后的队列需要显式继续；临时 Side chat 不作跨刷新恢复承诺。
- 审批回复属于当前原生请求与连接 epoch。旧请求不能在新连接中盲目回复；进程内重放通过并不等于任意原生进程重启后都能恢复待审批事项。
- 托管工作树删除要求干净且未占用，不使用强制移除，不删除分支。存储清理只针对经预览和再次校验的本应用数据；无法确认引用或占用时拒绝操作。
- 自动检查没有调用模型、使用真实 Cloudflare 凭据或更改现有部署。没有以重启公网服务作为验收手段；原生进程退出后的任务不可无损恢复仍是已知限制。

## 补充修复与定向回归

首轮 275 项统计之后又加入以下 P1 修复与定向测试；最终 292 项统计及完整干净检出复验已经包含这些新增检查。

- **稳定私有锁**：提交、队列、附件和开发工具采用 OS-backed SQLite 事务锁，测试同时恢复两个旧标记争用者、持锁进程被 SIGKILL 后两个等待者依次获得占用、SQLite inode 保持不变，以及活跃旧版拥有者被拒绝。增加同进程描述符关闭、父目录别名与硬链接/符号链接路径检查，避免本地竞争者意外解除外部锁。
- **未知提交阻塞**：排队的 unknown 回执不允许以立即发送、继续或重排绕过 FIFO；直接提交处于 prepared/dispatching/unknown 时同样阻止后续队列派发与相关操作。新增会话锁内再次检查，覆盖队列预留后另一直接提交变成未知结果的竞争。
- **附件及开发工具共用锁**：上传、会话绑定与预览清理互斥；清理和不同开发工具实例不能通过删除锁 inode 绕开对方，绑定后文件重新验证。
- **工作树子目录占用**：原生已加载会话、队列和启用/运行中的 Scheduled 使用工作树子目录时均阻止移除；真实路径别名被识别，相邻目录不误判，失联或无法识别的目录按占用处理。
- **真实协议故障注入**：主动切断替身的共享 Unix WebSocket，验证自动重连、原线程运行状态重读、审批 epoch 轮换及原生重新发出的审批才可操作；原生已接收而响应丢失时以精确 clientId 对账，执行次数保持一次。隔离替身退出码 23 后提交保持 unknown，重启实例的空闲状态不冒充原任务继续；继承标准输出管道的自有子进程组在 `exit` 时清理。此检查不承诺清理恶意脱离进程组或忽略 SIGTERM 的进程。
- **跨网关重复 RPC**：prepared 回执仍表示正在处理，不伪装为发送被拒绝；只有明确 rejected 才允许浏览器提示手动重试，原生错误代码保留。

这些测试不授权新旧网关同时运行。升级必须停止共享同一 Codex home 的所有旧 WebUI 网关，保留 receipt/queue 和 SQLite 锁及 sidecar，不手工删除锁。本轮没有重启公网服务。

## 人工验收回归清单

使用者已确认通过，以下清单保留供后续版本回归。使用隔离测试工作区和非敏感文件；不把验证码、认证 Cookie、JWT 或真实提示词放入公开报告。

1. **登录与返回**：固定域名 Access 和临时地址分别完成允许邮箱 OTP；错误邮箱被拒绝。退出、令牌到期、返回原页面后恢复正确会话和草稿；不得自动重发消息。
2. **软键盘与中文输入**：横竖屏下打开/关闭键盘、中文候选确认、多行输入、发送快捷键和附件选择；输入框与发送按钮不被键盘或安全区域遮挡，IME 确认不误发送。
3. **滚动和抽屉**：长回复、代码块与表格只能在各自区域横向滚动，整页不横移；左抽屉滑动关闭不抢夺纵向阅读；右面板、Files、编辑器和 Side chat 不超出可视区域。
4. **发送与运行**：慢网络点击发送立即出现反馈，连续点击不重复执行；运行时选择 steering/排队，编辑/重排/取消后队列与另一页面一致；中断和未知结果时明确暂停。
5. **审批与提问**：显示、滚动和完成批准/拒绝及文本回答；后台返回或重新认证后重新读取有效请求，陈旧批准不执行。主会话与 Side chat 请求不串线。
6. **附件和编辑**：拍照/照片库/文件上传、缩略图、预览、Library 可用；取消上传、失败重试、编辑冲突及未保存内容提示正确。选用无敏感内容的小型测试文件。
7. **后台生命周期**：锁屏或切后台约 1、5、10 分钟后返回；检查系统回收、页面刷新/bfcache、事件新鲜度、草稿和队列。明确区分 UI 恢复、原生继续工作和任务已中断。
8. **网络切换**：Wi-Fi 与蜂窝互换、短时飞行模式、连接恢复；认证失效停止循环重连，登录后不重复执行。记录成功恢复耗时及无法确认的提交提示。
9. **多端观察**：与 Desktop/第二个浏览器同时打开隔离会话，核对活动轮、队列及审批状态；外部并发限制按本文如实保留，不以单次成功宣称竞态已消除。

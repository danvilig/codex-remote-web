# Codex Remote Web 0.2.1-beta.1

This prerelease focuses on conversation performance and day-to-day use on desktop and mobile browsers.

- **Open long chats faster.** Load recent turns first, fetch earlier messages on demand, and preload pinned chats. Keep streamed replies visible when switching between chats.
- **Queue follow-ups while Codex works.** Edit queued messages in place, add images, or switch to steering. Review the message when checking uncertain delivery.
- **Follow work as it happens.** See live updates, expand completed activity when needed, and open files from the turn's edited-file summary. Code blocks, web searches, citations, and HTML previews have dedicated presentation.
- **Keep the composer compact.** A single row shows TTFT, output speed, cache hit rate, estimated turn cost, token totals, and context usage. Project names have more space in the sidebar and composer.

Cost uses OpenAI Standard API pricing for reported text tokens in the current turn. Browser chat previews are held in the current tab. Earlier history remains available from the server.

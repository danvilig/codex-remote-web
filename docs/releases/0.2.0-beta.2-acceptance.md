# 0.2.0-beta.2 candidate verification

The platform workflow records the source commit and exact artifact checksum for each run. It checks the native CLI, packaged setup, real terminal, and installer. For macOS, compare the macOS 15 and macOS 27 reports to the same DMG checksum. A mount or launch result does not prove visible UI rendering; that check has its own evidence. Ad hoc code signatures do not verify manual Gatekeeper approval, Safari download quarantine, or login/logout on a user's Mac.

On Linux, deployment and portable fixtures run outside HOME and reject accidental use of the host JavaScript runtime. The Docker test checks that Bun, Node.js, the Go toolchain, and Node addons are absent from the runtime image. All tests use local fixtures and do not exercise real accounts or models.

Windows and Linux desktop jobs measure the exact installed MSI/DEB payload. The reports identify the source commit and installer SHA-256, and contain archive size, installed file bytes and allocated bytes. Publish only the candidate whose system WebView controls, background gateway continuity and uninstall all passed. Measurements exclude the OS-managed WebView and its dependencies.

Prior development evidence applies only to commit `aca9141` and its DMG, SHA-256 `2b0c609a908d1e7d9ab5b5d73e858b3baa41455e4c9a8ea3a5b7396962b34a76`. The download was 7,773,168 bytes; Finder installation used 8,093,696 allocated bytes (16,110,089 logical bytes). [Native run 44450870823](https://github.com/danvilig/codex-remote-web/actions/runs/44450870823) passed macOS 15.8.2. macOS 27.0.1 passed functional checks but its WindowServer capture reported zero sidebar ink pixels. The maintainer reported that the application worked on a physical Mac without specifying the system version. These results do not count as acceptance of a Beta.2 artifact.

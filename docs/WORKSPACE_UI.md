## 第二轮：Dock 与可编辑设置

根据用户补充的当前 Codex Desktop 截图，明确区分最左侧独立 Dock 和内侧可收起的会话侧边栏。账户头像固定在 Dock 底部，头像菜单可进入设置；第三轮按最新反馈移除了头像上方的独立设置按钮。收起会话侧边栏后账户的位置与功能保持可用，侧栏内不再显示设置或账户底栏。小屏隐藏 Dock 时，同一账户控件移入抽屉，避免复制账户状态或 DOM ID。未登录时显示本地账户占位头像，不再把账户命名为 Settings。

| 设置 | 当前行为与保存范围 |
| --- | --- |
| 模型、推理强度 | 从当前服务的模型目录和支持级别生成，写入浏览器偏好并用于后续真实 turn 参数 |
| 发送按键 | Enter 或 Ctrl/⌘+Enter，Shift+Enter 换行；IME 确认不触发发送 |
| 主题、语言、聊天字号、代码字号 | 浏览器保存，立即作用于界面、消息、工具输出或 Diff |
| 审查布局、长行换行、默认展开 | 浏览器保存，与 Review 面板工具按钮双向同步 |
| 网页搜索、推理摘要、回复详细程度 | 显式点击保存，经原生配置接口写入服务端用户配置；新会话生效，项目/托管层可能覆盖，支持程度取决于模型 |
| 项目目录 | 设置页可调用真实目录选择器，选择后进入该项目的新会话 |
| 完成通知 | 已接通浏览器通知能力；受浏览器支持和用户授权约束 |

保存服务端配置时只提交发生变化的白名单项，并用版本号防止覆盖其他客户端的改动。加载、保存和错误状态可见；不会返回原始配置或凭据。开发验证仅在隔离协议替身中写配置，本机真实 Codex 用户配置仅做读取检查。

本轮新增配置校验/过滤/并发单元测试、原生设置保存与刷新、模型级别联动、键盘实际派发、字体及 Review 实际呈现、登录头像菜单、Dock 在侧栏收起前后的坐标与可操作性、小屏抽屉和设置层级测试。截图含 `workspace-dock-collapsed.png` 和 `workspace-settings-configuration.png`。

## 会话与草稿保护

草稿（文本及引用）按会话隔离；新任务按项目或无项目状态隔离，保存在当前标签页的 sessionStorage。刷新和重新登录不会自动提交草稿。最多保留最近 20 份；单份超过 25 万字符、序列化总量超过约 100 万字符的内容只在内存中保留，关闭标签页或浏览器清理存储不属于持久化保证。存储不可用时仍可正常输入和切换，但不能保证刷新恢复。

发送时固定会话、模型和权限选项，等待恢复/创建会话期间切换聊天会取消后续执行，原消息回到原上下文的草稿。执行请求已经发出后，切换聊天不会将回复或错误写入当前聊天；失败消息与后续输入合并。客户端同时仅允许一个待完成的发送/停止请求，避免连续点击重叠派发；这不是服务端幂等保证，不会在不确定的网络错误后自动重发执行请求。

测试 `bun run test:conversation-safety` 使用隔离协议替身，覆盖慢恢复、慢创建、迟到响应、发送失败、重复提交、刷新恢复与手机新任务抽屉关闭，不调用真实模型。


## 右侧工具标签与模型滑杆

右侧每种工具保留独立标签，可通过 ×、鼠标中键或聚焦后的 Delete 关闭；左右箭头及 Home/End 切换。关闭当前标签选择相邻项，关闭最后一项收起面板，下次打开回到工具列表。当前每种工具仅保留一份，尚不支持同时创建多个 Browser 或 Terminal。切换工具、隐藏面板保留现有终端；关闭终端标签会关闭 WebSocket 并结束 Shell。Shell 正常退出或运行时失败后显示重连入口，不自动循环启动。网络断开最多自动重连三次，Access 过期后停止重连并进入登录恢复流程。

模型弹层提供当前模型支持的离散推理强度滑杆，可鼠标/触摸拖动或键盘调整，名称和档位直接对应模型协议；只有单档时禁用滑杆。重置同时恢复服务端标记的默认模型及该模型的默认推理强度，清除对应浏览器覆盖；模型切换继续使用现有选择与存储键。

`bun run test:panel-controls` 使用隔离 App Server 替身和真实 PTY 验证 Shell 输出、退出/重连、标签切换/关闭、滑杆键盘/重置/持久化和手机端边界。

## 回答操作、Side chat 与输入工具

已完成的轮次默认收起工作过程，最终回答保持可见；长回答默认限制高度，可手动展开。工作过程和长回答的展开选择在当前页面轮询中保留。回答左下角直接提供复制与 Fork：复制完整最终回答的 Markdown，排除工作日志和文件变更统计；Fork 使用原生 `thread/fork.lastTurnId`，包含所选轮次、排除后续轮次，不自动执行新消息。文件变更以默认收起的摘要展示，可打开 Review。

右侧 **Side chat** 使用原生 `thread/fork` 的 `ephemeral: true`、`excludeTurns: true`，从主聊天最近完成轮次创建临时上下文分支；没有主聊天时使用原生临时 `thread/start`。不进入持久会话列表，分支后双方消息独立。可选中文字右键“在侧边聊天中提问”，或使用 `/side`、`/side <问题>` 准备草稿；这些操作均不自动执行。

隐藏右面板或切到其他工具会保留当前侧聊；关闭 Side chat 标签、刷新或离开页面会丢弃，并中断该侧聊自己的活动回合。每个页面保留一份临时侧聊，前端定期保活，失去保活十分钟后服务器清理。审批和问题卡片可直接在侧聊回答。断线后读取网关内存事件缓存，不重新发送执行请求；网关/App Server 重启后侧聊不可恢复，普通会话保持原有持久行为。

“保存为普通聊天”是显式上下文转存：原生临时线程不支持 `thread/resume`、`thread/turns/list`、直接 Fork 到磁盘或 Goal。网关建立持久原生主对话历史前缀，再通过受限 `thread/inject_items` 导入侧聊可见消息和工具记录；图片保留文件引用。导入内容属于模型上下文，不会伪造成原生历史轮次，后续发送可继续使用；它不是原生内部执行状态、审批状态或隐藏推理的无损迁移。保存不启动模型，不重放工具，活动回合必须先停止。Goal 在侧聊菜单中禁用，普通聊天可用。

输入框 **+ → Goal** 使用原生线程目标，可保存目标、可选 token 预算、暂停、恢复和清除。保存目标不自动发送提示词；用户发送消息后由 Codex 原生目标机制处理。旧版 App Server 不支持时显示错误，不模拟目标执行。**Skills and plugins** 从当前项目实际启用的原生技能生成，安装了 Visualize 时可选择它；选择先加入草稿，明确发送时重新验证启用状态并加入原生 `skill` 输入。安装、卸载和启停仍在 Customize 中操作。

聊天操作中的终端开关直接打开终端；右侧工具列表仍可选择独立 Terminal 标签。721–1000px 的窄桌面同时打开右侧工具时收起左侧列表，避免把聊天挤成窄条；重新打开左栏会关闭右侧工具。手机仍使用完整宽度的工具面板。

Files 文件树铺满面板，界面标签随中英文设置即时往返切换，文件名、路径和内容保持原文。打开 Markdown 默认显示净化后的排版预览，可切换源码；其他文本显示行号与源码。面板宽度达到 580px 时，文件内容在左、230px 文件树在右；窄面板显示完整文件预览，通过“返回文件树”保留目录展开状态并返回。

点击文件工具栏的“编辑文件”进入 CodeMirror 编辑模式；高亮跟随文件语言和明暗主题，未知语言按纯文本处理。支持撤销/重做、查找、Tab 缩进，Ctrl/Cmd+S 保存。Markdown 在预览模式启用编辑后可点击段落，在对应位置编辑原始 Markdown 并查看实时排版；“完成”或 Ctrl/Cmd+Enter 返回排版。只替换当前段落的源码范围，保留其他内容、段间空行和引用定义；也支持切换全文源码编辑。它不将渲染 HTML 反向转换为 Markdown。

未保存状态显示在标题和状态栏；切换文件、工具、关闭预览时草稿保留在当前页面内存，离开/刷新有浏览器提示，不自动保存或执行。保存使用内容版本校验；磁盘文件被其他程序或标签页改动时拒绝覆盖，保留草稿并提供复制入口，重新加载前会确认放弃修改。支持不超过 256 KiB 的现有 UTF-8 文本文件，不创建、删除或重命名文件。只读、多硬链接、二进制、非 UTF-8 和敏感文件不允许编辑。

桌面和平板分栏模式可以拖动左右侧栏的内侧边缘调整宽度；也可以聚焦分隔线，用方向键调整、Shift 加速、Home/End 到达边界，双击恢复默认。宽度保存在当前浏览器，并随视口变化限制尺寸，给主对话保留空间。右面板工具栏提供最大化/还原，Escape 优先还原；调宽和最大化均不重新加载当前文件或销毁工具会话。手机使用整屏工具面板，不显示调宽分隔线。

`bun run test:workspace-features` 包含上述隔离交互回归；`bun run test:conversation-tools:native` 可在安装了 Codex 的机器上使用全新临时 HOME 验证原生目标存取、临时分支及显式上下文转存，不读取真实凭据、不启动模型回合。

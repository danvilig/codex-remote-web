# 开发路线

## 当前预发布基线

已完成基础协议闭环、会话事件隔离、原生计划/问题卡片、进程内待批请求恢复和多端同步；独立 PTY 与 Review 写操作默认关闭。工作区已具备独立 Dock、项目注册/分组/排序、设置、真实插件/技能元数据和基础文件/图片浏览。

`0.2.0-alpha.1` 阶段完成源码与测试分层、自有视觉资源、Cloudflare Access 单身份验证、到期重连与草稿恢复、原生服务部署模板、发布白名单及校验和、CI 和手动预发布产物流程。已完成真实域名 Access 登录及受保护 Quick Tunnel 连通验证；发布回归使用模拟协议和本地密钥，不重复修改真实部署。

## Alpha 后的工作区完善

已实现平板分栏、右面板切换、主题下拉框、Access 邮箱头像、通知排序、Dock 图标显隐、存储占比图；会话 Files、本机图片、上传附件 Library、输入框上传和项目下拉，以及插件/技能基本管理。Scheduled 已支持服务器后台固定间隔执行、审批等待、暂停/停止和持久记录；异常恢复不自动重放。此批改动位于后续开发分支，原本地 Alpha 候选归档保持不变。

Files 已采用按需展开的开发者文件树，支持键盘导航、搜索、相对路径复制和带行号预览。Side chat 已共用主输入框的样式与模型/推理/权限控件，并支持独立附件、项目文件引用、计划与已启用技能。侧聊已改为原生临时分支，支持内嵌审批/问题、选中文字或 `/side` 入口、显式上下文转存与关闭清理；Goal 按原生限制仅用于普通聊天，临时侧聊不做跨刷新恢复。

`0.2.0-alpha.2` 已完成验收，加入发送反馈与提交协调、持久主会话队列、AGENTS.md 预览编辑、托管工作树生命周期、受限清理及只读 MCP 清单。验证范围见本次验收报告，旧 alpha.1 候选保持不变。

## 下一阶段：剩余验收与公开

- 真实域名、Access 单邮箱登录和公网工作区已验证；继续测量撤销时效与用户服务跨主机重启行为。
- HTTP、WS、SSE、到期重连与草稿恢复已有隔离回归；继续进行公网网络切换、断线执行和重新登录状态恢复的专项验收。
- 确认独立公开仓库、维护者身份和私密安全报告渠道，再公开预发布版本。

## 执行可靠性

- 核对结果未知的提交、外部 Desktop 并发与原生条件式启动限制；不承诺原生 exactly-once。
- 网关与长寿命 App Server 解耦，明确网关重启与页面断线的区别。
- 持久化待批请求和必要状态，验证进程重启恢复。
- 结构化诊断、有限日志、备份和可验证的版本回退。

## 功能扩展

设置已补齐中英文与双语搜索、原生权限/记忆/附加指令、归档恢复，以及只读存储/工作树信息。项目 AGENTS.md 已支持修订检查与 Markdown 预览；托管工作树仅可移除干净未占用目录并保留分支；清理仅限未使用的过期 WebUI 数据。Desktop 专用选项须有真实运行时支持后再开放。

附件上传已支持；完整 MCP 交互、插件账户连接管理，以及工具时间线和 Diff 阅读体验。站点管理/部署、图片生成与云端 Library 尚未实现；Native Search / Image Gateway 以真实工具注册、provider 能力和协议支持为前提，作为独立阶段开发。暂不开展多租户或换框架重写。

## 网页接入向导

已实现：复用远程管理 Tunnel 的本机 Web 向导、原生用户服务安装、变更预览、部署清理、诊断、独立入口与模拟回归。真实域名与登录、受保护临时访问已完成连通验证；用户服务跨退出/主机重启行为、实际撤销时效属于部署专项检查。已补充本机连接器识别、专用 Tunnel 创建和独立连接器服务、子域名及 @ 输入；临时访问已支持无需域名/账户的单邮箱 OTP、状态、二维码与停止控制；cloudflared 软件自动安装和 Terraform 输出留待后续。
